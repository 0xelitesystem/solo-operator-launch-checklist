# The launch checklist

The full pre-launch checklist for a solo operator, in one place.

## Foundation

- [ ] The product does one clear thing, statable in a sentence.
- [ ] The single primary action for visitors is defined.

## Legal and policies

- [ ] Privacy policy exists and is linked, if any data is collected.
- [ ] Terms of service exist and are linked.
- [ ] Refund policy is stated before purchase, if anything is sold.
- [ ] Subscription renewal is disclosed and cancellation is easy, if applicable.
- [ ] Affiliate, AI, and endorsement disclosures are present where they apply.

## Security and technical

- [ ] No secrets or keys in front-end code or public repositories.
- [ ] HTTPS site-wide, with HTTP redirecting to it.
- [ ] Basic security headers are set.
- [ ] Backups run automatically, cover files and data, are stored off-site, and a restore has been tested.
- [ ] Rate limits and a spending ceiling protect anything that costs money.

## Content and conversion

- [ ] The page states what the product is in its first lines.
- [ ] The primary action is the most obvious thing on the page.
- [ ] Copy is honest, with no inflated claims or fake social proof.
- [ ] The full path from landing to primary action has been tested end to end.

## Distribution

- [ ] You know where the first visitors will come from.
- [ ] The first message or post is ready before launch, not improvised after.

## The one-line version

Ship something focused and complete: foundations before polish, the unglamorous items confirmed, the conversion path tested, and a plan for the first visitors. A solo operator's launch succeeds on completeness, not flash.
